# 📝 Sign-up Form

A sign-up form layout recreated with HTML and CSS.

## About the Project

This project recreates a sign-up page featuring a visual sidebar, registration form, input validation states, and account creation call to action.

- Recreating a reference layout
- Structuring forms with HTML
- Styling a split-screen interface with CSS
- Implementing form validation states
