# 🎮 Tic-Tac-Toe

A responsive two-player Tic-Tac-Toe game built with HTML, CSS, and vanilla JavaScript.

## About the Project

A browser-based Tic-Tac-Toe game for two local players. Enter custom player names, select cells to place X and O marks, and play until there is a winner or a draw.

## ✨ Features

- Supports two local players with custom names
- Detects wins across rows, columns, and diagonals, as well as draws
- Restarts the board and starts a new round

## 🎯 What I Practiced

- Object-oriented programming in JavaScript
- Separating game logic from DOM and interface concerns
- Managing and updating application state
- Handling turns, wins, draws, and restarts

## ⚡ Main Challenge

Managing state was the biggest challenge. I worked on keeping track of the board, active player, game progress, and win or draw status without allowing the interface and game logic to become tightly coupled.

## 🕹️ How to Play

1. Enter names for both players.
2. Select **Start Game**.
3. Take turns choosing cells on the board.
4. The first player to connect three marks wins.
5. Select **Restart Game** to play again.
