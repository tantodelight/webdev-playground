# 📊 Admin Dashboard

An admin dashboard layout recreated with HTML and CSS.

## About the Project

This project recreates a dashboard interface featuring a navigation sidebar, header, project cards, announcements, and trending sections.

## 🎯 What I Practiced

- Recreating a reference dashboard layout
- Structuring complex page sections with HTML
- Building layouts with CSS Grid
- Working with nested grids and alignment
- Styling cards, navigation, and dashboard components
